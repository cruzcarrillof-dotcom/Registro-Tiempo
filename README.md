# Registro de Tiempo — versión 1
Aplicación Android base para registrar tiempos muertos/actividades de producción.

Incluye:
- Descripción
- Inicio y fin con botones
- Cálculo automático de duración
- Total acumulado de la sesión
- Historial visible

## Compilar
Abrir la carpeta en Android Studio y ejecutar `assembleDebug`.
El APK quedará en `app/build/outputs/apk/debug/app-debug.apk`.
