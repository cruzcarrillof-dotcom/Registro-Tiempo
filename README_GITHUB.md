# RegistroTiempo v1 — compilación automática

Este proyecto incluye GitHub Actions para generar el APK automáticamente.

## Cómo obtener el APK

1. Crea una cuenta en GitHub.
2. Crea un repositorio nuevo.
3. Sube **todos los archivos y carpetas** de este proyecto al repositorio.
4. En GitHub entra a **Actions**.
5. Selecciona **Build Android APK**.
6. Pulsa **Run workflow**.
7. Cuando termine, abre la ejecución y busca **Artifacts**.
8. Descarga `RegistroTiempo-v1-apk`.
9. Descomprime el archivo y tendrás `app-debug.apk`.
10. Pásalo al teléfono Android e instálalo.

La compilación es de tipo debug y no requiere publicar la aplicación en Google Play.
